VideoStation Privacy Policy

Last updated: November 9, 2026

VideoStation is a private publishing tool operated by the owner of the YouTube channel Whimquuark. It runs only on the owner's own computer and is used only by the owner to upload and manage videos on their own channel. It is not offered to the public.

What data VideoStation accesses

When the owner signs in with Google, VideoStation requests these permissions through the YouTube API Services:

  • youtube.upload – to upload the owner's own videos to the owner's own channel.
  • youtube.readonly – to read the channel's basic information and the status of its videos (for example processing status and privacy setting).
  • yt-analytics.readonly – to read summary statistics such as views and watch time for the owner's own videos.

How the data is used

The data is used only to upload the owner's videos and to display their status and statistics on a dashboard on the owner's own computer. VideoStation does not use the data for advertising, does not build profiles of viewers, and does not access any other user's channel.

Storage and security

  • Google sign-in tokens are stored only in the operating system's credential store (Windows Credential Manager) on the owner's computer. They are never stored in code, configuration files, logs, or chat messages.
  • VideoStation stores only video IDs, upload status, and summary statistics for the owner's dashboard.
  • No data is sent to any server operated by VideoStation; the tool communicates only with Google / YouTube APIs and the owner's private Discord server for status notifications.

Sharing

VideoStation does not sell, rent, or share any data obtained from YouTube API Services with third parties.

Revoking access and deleting data

Access can be revoked at any time at Google Account → Third-party connections. Revoking access, or removing the stored credential from the computer, stops all access. Locally stored status data can be deleted by the owner at any time; it is also deleted within 30 days after access is revoked.

Third-party terms

VideoStation uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
